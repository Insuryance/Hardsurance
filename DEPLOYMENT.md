# Hardsurance deployment

This repository is ready for GitHub and Vercel.

1. Run `npm install`.
2. Run `npm run dev` for local development.
3. Run `npm run build` to verify production output.
4. Import the GitHub repository into Vercel with the default Next.js settings.
5. Add `hardsurance.com` and `www.hardsurance.com` in Vercel Domains.
6. Copy the DNS records shown by Vercel into Hostinger DNS.

No environment variables are required for this marketing-site version.
